이럴 때 사용합니다

  • 입고 대기 구역에 쌓인 물건을 보관 구역으로 옮길 때
  • 유통기한이 임박한 로트를 출고 대기 구역으로 미리 빼둘 때
  • 온도 관리가 필요한 품목을 저온(COLD) 구역으로 재배치할 때
  • 사용 중지 예정인 구역을 비울 때

사용 중지된 구역에서 빼내는 것은 허용됩니다. 구역을 비우는 작업 자체를 막으면 재고가 갇히기 때문입니다.
