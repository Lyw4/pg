입고 처리 규칙

  1. 사용 중지된 품목 / 구역에는 입고할 수 없습니다.
  2. 로트번호를 비우면 L{제조일}-{품목코드}-{순번} 형식으로 자동 부여됩니다.
  3. 유통기한은 제조일자 + 품목의 유통기한 일수로 자동 계산됩니다.
  4. 같은 로트가 같은 구역에 들어오면 수량이 합산되고, 새 구역이면 적재 행이 생성됩니다.
  5. 구역의 최대 적재 수량을 초과하면 입고가 거부됩니다.
