선입선출(FEFO) 출고 규칙

  1. 유통기한이 가장 먼저 도래하는 로트부터 차감합니다. 유통기한이 같으면 구역 코드 순입니다.
  2. 한 로트로 부족하면 다음 로트로 이어서 차감합니다. (다중 로트 분할 출고)
  3. 이미 유통기한이 지난 로트와 사용 중지된 구역은 출고 대상에서 제외됩니다.
  4. 출고 가능 수량이 부족하면 부분 출고 없이 전체가 롤백됩니다.
  5. 차감 순서 : 구역 재고 → 로트 수량 → 품목 전체 재고, 그리고 출고 이력 기록
