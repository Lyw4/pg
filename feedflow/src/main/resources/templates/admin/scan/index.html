스캔 즉시 입출고 -
스캔한 로트에 수량이 합산됩니다. (유통기한은 기존 로트 값을 유지)
출고 로트는 지정하지 않습니다. 유통기한이 가장 임박한 로트부터 자동 차감(FEFO)되며, 처리 후 실제 차감된 로트가 표시됩니다.

사용 방법

  1. 스캔 시작을 누르고 카메라 권한을 허용합니다.
  2. 바코드 / QR 코드를 화면 가운데 가이드에 맞춥니다.
  3. 인식되면 자동으로 품목·로트·구역별 재고가 표시됩니다.

스캔이 완료되면 이 자리에 품목·로트·재고 정보가 표시되고, 위쪽에 즉시 입고 / 출고 패널이 열립니다.
